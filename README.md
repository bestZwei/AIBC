# AIBC - AI广播电台

AIBC是一个由AI驱动的在线广播电台项目，模拟传统广播电台体验，但内容完全由AI实时生成。

## 项目特点

- 多个AI主播频道，每个频道有特定主题和风格
- 连续的音频播放体验，模拟真实广播电台
- 用户可以提问或建议话题，影响广播内容
- 实时生成的AI内容，通过TTS转换为流畅语音
- 模拟广播电台的过渡和间歇效果

## 技术栈

- 原生JavaScript、HTML5和CSS3
- Web Audio API用于音频处理
- 通过OpenAI兼容接口生成内容
- Edge格式TTS接口合成语音
- 适配Cloudflare Pages部署

## 前端设计

- **字体**：Inter（界面）+ JetBrains Mono（数字/标识）
- **配色**：中性深色背景（`#0a0a0a`）+ 细边框卡片 + Vercel 蓝（`#0070f3`）强调色
- **布局**：玻璃拟态吸顶导航、网格背景、圆角卡片、响应式双栏布局
- **主题**：暗色 / 亮色主题一键切换，偏好本地持久化
